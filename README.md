# 国家电网电力（sgcc_power）

将“网上国网”账户中的用电数据接入 Home Assistant 的社区集成。针对旧版
state_grid 系集成自 2026 年起 **95598 网页登录链路失效、无法获取数据** 的问题
重新实现：登录改走网上国网 App 通道——不需要浏览器、不需要 OCR/大模型识别
验证码、不需要 Docker，账号密码即可完成配置。

> 这是社区维护的非官方集成，与国家电网有限公司没有隶属或授权关系。它依赖
> 网上国网 App 的非公开接口，服务端升级后可能暂时失效。请勿用于计费、结算
> 或其他需要法律效力的场景。南方电网账户不适用。

## 为什么旧集成会登录失败

旧版集成（bilezhou / lxg20082008 一系）通过 95598 网上营业厅网页登录，
需要自动求解滑块验证码。国网页面多次改版后，旧登录体携带的字段已被服务端
直接拒绝，叠加按登录标识的风控判定，自动登录大面积失效——集成本身还在运行，
但数据停留在最后一次成功刷新。本集成不再触碰网页登录链路。

## 功能

### 登录与数据

- 使用网上国网手机号和密码登录（App 通道，无验证码环节）
- 服务端要求新设备验证时，按提示输入一次 6 位短信验证码
- 登录令牌约 15 天有效，过期自动用已保存的密码重新登录；剩余不足两天即
  主动续期，避免服务端提前作废令牌导致的数据断流
- 支持一个账户下的多个用电户号，每户号独立设备与传感器

### 传感器（每户号 19 个）

| 分组 | 传感器 |
|---|---|
| 日 | 昨日用电量、昨日峰/谷/平/尖电量 |
| 月 | 本月用电量、本月峰/谷/平/尖电量、**本月电费**、历史欠费 |
| 结算 | 上一结算月电量/电费、本年累计电量/电费、上月抄表读数 |
| 账户 | 账户余额、应交金额 |

- “本月电费”优先用官方字段（上游 estiAmt），上游不提供的地区自动按配置
  的电价口径估算，并在属性 `口径` 中标注数据来源
- “本月用电量”与“本年累计电量”带 `total_increasing`，可直接进能源面板
- 昨日用电量带 `daily_history`、上一结算月电量带 `monthly_bill_history` 属性

### 成本统计回填（能源面板即开即用）

- 每次刷新把日用电量按实际日期回填外部统计 `sgcc_power:total_energy_<户号>`，
  能源面板立即可选完整历史（约 12 周），不必从安装日开始积累
- 日电费同理（`sgcc_power:total_cost_<户号>`），口径可选：
  - **固定单价**（`price_per_kwh`，默认湖南省居民第一档基准价 0.588 元/kWh，
    按各地公示电价自行修改）
  - **阶梯电价估算**（湖南居民季节阶梯：春秋月 200/350 kWh、冬夏月 200/450，
    二/三档加价 0.05/0.30 元；实测与官方月度电费偏差约 0.1%）
- 上游提供真实日电费的地区自动优先用真实值
- 改电价/开关阶梯后，成本统计自动整体重算
- 幂等与自愈：游标持久化、上游修订历史自动重导、导入失败自动重试

### 其他

- **手动刷新**：服务 `sgcc_power.refresh` 跳过刷新间隔立即拉取最新数据
  （充值后查看最新余额等场景）
- **改密码**：在集成选项里填“新密码”，先走 App 通道验证（需要时含短信
  验证步骤），成功才保存，失败保持原密码
- **诊断**：集成页下载脱敏诊断 JSON（不含手机号/密码/令牌/完整户号）
- **旧版兼容层**：刷新后写入 `.storage/state_grid.config`，state_grid_info
  等辅助集成及其卡片继续有新数据（选项可关）
- **官方品牌图标**：集成自带国网官方 logo（HA 2026.3+ 本地加载）

## 安装

### HACS

1. HACS → 集成 → 右上角菜单 → 自定义存储库
2. 添加 `https://github.com/yahooor/sgcc-power-ha`，类别 **集成**
3. 搜索“国家电网电力”并下载，重启 Home Assistant

### 手动安装

1. 从 [Releases](https://github.com/yahooor/sgcc-power-ha/releases) 下载 zip
2. 将 `custom_components/sgcc_power` 复制到 HA 配置目录的 `custom_components`
3. 重启 Home Assistant

## 配置

1. 设置 → 设备与服务 → 添加集成 → 搜索“国家电网电力”
2. 输入网上国网手机号和密码
3. 如收到新设备安全验证短信，继续输入 6 位验证码

**选项**（设置 → 设备与服务 → 国家电网电力 → 配置）：

| 选项 | 说明 |
|---|---|
| 查询最近几个月 | 1–3 个月，默认 2 |
| 刷新间隔 | 6–24 小时，默认 12 |
| 旧版兼容文件 | 写 `.storage/state_grid.config`，默认开 |
| 电价（元/kWh） | 成本估算基准价，默认 0.588（湖南一档）；0=关闭成本统计 |
| 阶梯电价估算 | 按湖南季节阶梯分段计价，默认关 |
| 新密码 | 修改网上国网密码时填写（验证通过才保存） |

> 改选项后集成会重载数据；若上游登录频控导致首次刷新失败，Home Assistant
> 会自动退避重试，最长可能十几分钟后生效，无需反复保存。

## 传感器数据说明

- 当天电量通常延后一至两天发布，属正常上游节奏；昨日用电量以 `latest_date`
  属性为准
- 预付费账户“应交金额”为 `unknown`；后付费账户显示当前应交
- 尖峰电量具有季节性（如湖南仅夏季数月有值），其余时段为 0 属正常
- 部分地区不开放抄表读数，显示 `unknown`
- 上游缺失的数据保留 `unknown`，不会填 0

## 能源面板接入

设置 → 仪表盘 → 能源 → 电网消耗 → 添加，电量与成本统计均在
“从统计”列表中（名称含“国家电网 累计”）。
